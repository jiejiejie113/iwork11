# 工序产量对比 - 纵向柱状图 + Tab 切换

## 目标

将当前"全工序垂直堆叠横向柱状图"改为"纵向柱状图 + Tab 菜单切换工序"。

## 改动范围

仅修改 `iwork/templates/iwork/dashboard.html`，后端 API 不变。

## UI 规格

### 多工序（≥2）

- 顶部显示 Tab 栏，按总产量降序排列工序
- Tab 标签格式：`工序 {stepno}`，当前选中 Tab 高亮
- 下方单个固定高度（300px）的纵向柱状图
- 点击 Tab 切换工序，销毁旧图表重建

### 单工序（=1）

- 不显示 Tab 栏
- 直接显示工序标题 + 总产量 + 纵向柱状图

## 实现要点

| 项目 | 当前 | 改为 |
|------|------|------|
| 图表方向 | `indexAxis: 'y'` | 移除，默认纵向 |
| Canvas 数量 | N 个 | 1 个（复用） |
| 工序切换 | 无（全部滚动显示） | Tab 菜单 |
| 高度 | 动态 `flowCount * 24 + 20` | 固定 300px |
| 图例 | 隐藏 | 保持隐藏 |

## 交互

1. 默认选中产量最高工序
2. Tab 切换 → `updateChart()` 更新数据
3. 单工序无 Tab
